## Perbaikan dan fitur

- Data Tendik/Dosen kini otomatis dikategorikan dari kolom Jabatan / Unit Kerja: yang memuat "Dosen" masuk kategori Dosen; lainnya masuk Tendik.
- Saat aplikasi diperbarui, data pegawai yang sudah ada akan dikategorikan ulang berdasarkan Jabatan / Unit Kerja. Data Mahasiswa tidak diubah.
- Pengaturan PDF hanya menawarkan font bawaan Dompdf/PDF, tanpa mendistribusikan font eksternal berlisensi.
- Menambahkan Reset Sistem dengan verifikasi password admin, backup sebelum reset, dan penghapusan data operasional tanpa menghapus akun atau pengaturan.
- Memperbaiki impor/sinkronisasi spreadsheet gabungan Tendik & Dosen serta validasi data pegawai.

## Catatan

- Reset sistem membuat arsip backup di folder `storage/app/backups` sebelum menghapus data.
- Pada instalasi desktop, migrasi dan pembaruan berjalan saat aplikasi dibuka. Instalasi hosting perlu menjalankan `php artisan migrate --force` setelah deploy.
