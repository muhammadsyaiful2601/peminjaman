Konfigurasi Awal Aplikasi

Sistem Peminjaman Barang — Politeknik Negeri Padang

Aplikasi berjalan offline penuh — tanpa XAMPP/Laragon dan tanpa internet. Konfigurasi email di bawah ini opsional: isi hanya jika ingin bukti peminjaman, pengembalian, dan reset password dikirim otomatis ke email peminjam. Email baru benar-benar terkirim saat komputer terhubung ke internet.

Untuk Brevo: key SMTP ada di menu SMTP & API (bukan API key v3).

Konfigurasi tersimpan hanya di komputer ini.
